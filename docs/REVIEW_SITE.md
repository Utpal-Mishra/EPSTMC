# Private reader review

The owner-only review site is available at:
https://epstmc-reader-review.utpalmishra21.chatgpt.site/

Sign in with the owning ChatGPT account. Start at the feed, open the fictional
council story, and inspect the original publication and its correction using
Publication history. The workflow page provides a guided path and explains the
recorded stages.

This is a fixed snapshot generated by the real WSGI reader from a temporary
fictional demo database. It is not a live database-backed deployment and it has
no browser controls for drafting, approval or publishing. Source links are
example.com placeholders; the story is not real news. No private editorial notes,
operator identity, credentials or database files are included in the projection.

Regenerate the pages using:

```bash
python preview_export.py --output /tmp/epstmc-reader-snapshot
```

The exporter calls `demo.seed`, `app.create_app` and the published data service.
It rewrites navigation into static pages while retaining the reader's content,
source anchors, version warning and correction history. An automated check
verifies all local links resolve and private fields do not appear in exported
history. All 43 local tests passed. Browser QA verified feed → story → version 1
and the earlier-publication warning. Private hosted access correctly presents the
ChatGPT sign-in gate.

Published review version: `appgprj_6b04bdf51930819196bfe67273bccb48~appgver_a49a02bbe4808191ba188cfea58c388a`.
The hosting identity is separate from the backend's GitHub repository, allowing
read-only evaluation without changing the production database or exposing the
editorial application publicly.
