# Website completion scope — 25 November 2026

This phase completes the connected browser website within the existing private runtime. It builds workspace navigation, guided authoring, feed routing, explicit offline reading, browser video production, settings/help and reliability; each WEB-01–WEB-08 unit has its own code/evidence commit and record.

Native iOS/Android applications and app-store release remain the original future roadmap. Paid provider generation requires actual credentials and account-supported models. Browser recording and browser voice are capability-dependent. Actual owner editorial approval is not implied by software deployment. No schedule or audience change is part of this phase.

See STEP_TRACEABILITY.md and docs/steps/WEB-01.md through WEB-08.md for acceptance criteria and separate results.
